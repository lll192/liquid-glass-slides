# ECharts 图表能力 · 决策框架

本 skill 内置 ECharts 图表能力（库文件 `assets/echarts.min.js`，由 `scripts/build.py`
在**检测到图表时才内联**进最终单文件 HTML）。本文档规定「何时加图、加什么图、放哪」，
确保图表真正有助于表达，且整体视觉与液态玻璃风格一致。

> **首要原则：宁可少加，不可硬加。** 只有页面承载「真实、可比较、可量化」的数据时才加图表；
> 为了凑图而编造数字，一律不加。

> **⚠️ 使用方式（对用户零代码）**：本节所有判断与 outline 字段都由 **AI 自动完成**。
> 用户使用本 skill 做 PPT 时只需描述内容需求，AI 扫描每页 → 判断是否加图 → 选图型 →
> 把 `chart` 字段写进 outline → 运行 build.py。**用户永远不需要读/写任何代码或字段**。
> 下文的 outline 写法只是「AI 与 build.py 之间的接口约定」，供 AI 参照执行。

## 1. 何时加图（扫描每一页后判断）

**应该加（信号）**
- 页面有**随时间变化的趋势**（年份/版本演进、增长曲线）→ 折线图 / 面积图。
- 页面有**跨多个对象的同一指标对比**（工具/方案/产品横评）→ 分组柱状图。
- 页面有**占比 / 构成**（份额、分布、组成）→ 环形图 / 饼图。
- 页面有**相关性 / 分布**（散点）→ 散点图。
- 数据维度 ≥ 3 且想一眼比较 → 雷达图。

**不应该加（信号）**
- 纯文字观点页、概念定义页（bullets / grid-cards / 要点）→ 文字自身已清晰。
- 代码演示页（two-column 代码块）→ 代码不是数据。
- 装饰性分隔页（section-divider）→ 已由图片/大数字承担。
- 已经自带强可视化的页面（timeline 时间线）→ 再加图会冗余。
- 只有一个大数字的统计页（stat-highlight）→ 用大数字本身即可；若想补趋势，可**新增一页**图表，不要挤在同一页。
- 任何需要**编造数字**才能画图的页 → 不加（宁可保持纯文字）。

## 2. 图表类型选择速查

| 数据形态 | 推荐图表 | 备注 |
|---|---|---|
| 趋势 / 时间序列 | line / area | 平滑曲线 + 渐变面积 |
| 类别对比（2+ 对象） | bar（grouped） | 分组柱，圆角 |
| 占比 / 构成 | pie / doughnut | 环形优先，白边 |
| 多维能力对比 | radar | 3–6 维 |
| 相关性 | scatter | 泡泡大小表权重 |

## 3. 放置位置（左文右图分栏）

- 使用专用 `chart` 布局：**左栏**放 eyebrow + 标题(title) + **同一张玻璃卡内的
  引导句(note)与关键结论(takeaway，可选但推荐)** + 底部注释(caption)；**右栏**放毛玻璃图表卡。
  note 与 takeaway 语义连续，必须合在同卡：note 为弱化说明行（灰），takeaway 为加重结论行（黑、加粗）；
  两者皆缺时卡片自动隐藏。eyebrow（大写标签）留在卡外。
  两栏在 grid 中并排垂直居中（`5fr / 8fr`），文字拥有独立栏位，**绝不会被图表挤到边缘**。
- 图表卡内 ECharts 容器高度用 `chart.height`（默认 `min(50vh,440px)`），不撑破视口。
- 窄屏（<880px）自动退化为上下堆叠。
- 不要把图表塞进已拥挤的文字页；必要时**单独成页**或紧跟在相关页之后。

## 4. 风格一致性（自动套用，无需手写）

`build.py` 对每张图自动套用「液态玻璃主题」（`applyTheme`），包含：
- 画布背景透明（`backgroundColor:'transparent'`），露出页面渐变与光斑；
- 配色沿用 iOS 蓝主色板 `['#0A84FF','#5AC8FA','#30D158','#FF9F0A','#BF5AF2','#FF375F']`；
- 坐标轴细灰、隐藏冗余刻度线、浅色分隔线；
- tooltip 为**磨砂玻璃**（半透明白底 + `backdrop-filter:blur` + 圆角阴影）；
- 柱体圆角、折线平滑、面积渐变、环形白边。

作者无需手动调样式即可得到与全站一致的图表。

## 5. outline 写法（AI 参照，用户无需关心）

```json
{
  "layout": "chart",
  "eyebrow": "生态规模",
  "title": "Mathlib 的规模增长（2017–2024）",
  "note": "可选的一句话引导",
  "takeaway": "可选的高亮关键结论（一句大实话，如「不到十年增长超 10 倍」）",
  "chart": {
    "height": "min(50vh,440px)",
    "option": {
      "xAxis": { "type": "category", "data": ["2017","2018","2019","2020","2021","2022","2023","2024"] },
      "yAxis": { "type": "value", "name": "代码行数（万）" },
      "series": [ { "type": "line", "smooth": true, "areaStyle": { "opacity": .22 },
                   "data": [10,18,40,58,80,92,100,120] } ]
    }
  },
  "caption": "数据来源：社区统计（示意）。不到十年增长超 10 倍。"
}
```

**约束**：`option` 必须是**纯 JSON 数据**——本管线用 `json.dumps` 直接注入，
不支持 JS 函数（如 `formatter: function(){}`）。需要格式化时，请预先把标签算好写进 `data` /
`label.formatter` 用字符串模板（ECharts 支持 `'{b}: {c}'` 这类字符串模板）。

## 6. 自检清单

- [ ] 该页是否真的有可量化、可比较的数据？（否 → 不加）
- [ ] 选的图类型是否匹配数据形态？（见 §2）
- [ ] 数据是否真实 / 有出处？（编造 → 不加，或明确标注「示意」）
- [ ] 图表是否独占成页或居中成卡，未挤压文字？
- [ ] option 是否为纯 JSON（无函数）？
- [ ] 重建后 `grep -c 'echart-'` 数量 == 图表页数量，且 `echarts.min.js` 已内联。
