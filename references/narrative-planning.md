# Narrative Planning

Choose a deck shape before laying out slides.

## Deck types
- **Teaching** — explain a concept step by step (concept → mechanism → example → takeaway).
- **Persuasive / Pitch** — problem → solution → proof → ask.
- **Report** — context → findings → metrics → next steps.
- **Product explanation** — what it is → how it works → why it matters → call to action.
- **Knowledge card** — one idea per slide, visual-first.

## Story structures
- Problem → Agitation → Solution → Proof → Action
- Past → Present → Future
- Why → What → How → So what
- Claim → Evidence → Implication

## Slide-by-slide spine
- Each slide = exactly one main point.
- Sequence for rhythm: open with a cover, close with a takeaway.
- Aim for a mix of archetypes (see slide-archetypes.md) so the deck breathes.
